# UI reference prototypes

The approved Design boards behind [`../ui.md`](../ui.md): `Main` (dashboard), `Course`, `Lesson`, `Quiz`, `Exam`, `Settings`, laid out by `canvas.json`.

They are `.dc.html` files that need the Design artifact runtime (`support.js`, not included) to render, so opening them directly in a browser will not work. Treat them as readable source for exact markup, spacing and token values. Private published copy: https://claude.ai/artifact/7Hh1A9cjkbTtq8THUVCoCN

Not application code: do not import or edit them. `ui.md` is the maintained spec; if a board and the spec disagree, fix the spec.
