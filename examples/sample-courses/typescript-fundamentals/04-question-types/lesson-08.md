Read the code and click the line, or lines, the question asks about. Click a selected line again to unselect it.

After checking, the code shows which lines were right, which you picked by mistake and which you missed, with an explanation underneath.

The same question can show a change as a diff, with added lines in green and removed lines in red, and ask you to review it. A line you leave unselected is a line you judged fine.
