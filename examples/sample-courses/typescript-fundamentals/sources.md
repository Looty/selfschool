# Sources

Numbers are stable: lessons and questions cite them as `[n]`. Never renumber; append new sources at the end.

1. [TypeScript Handbook: The Basics](https://www.typescriptlang.org/docs/handbook/2/basic-types.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: static type checking, type inference, erased types.
2. [TypeScript Handbook: Everyday Types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: primitives, arrays, object types, unions, type aliases.
3. [TypeScript Handbook: Narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: `typeof`, truthiness, equality, `in`, `instanceof`, type predicates, discriminated unions, `never` and exhaustiveness checking.
4. [TypeScript Handbook: Object Types](https://www.typescriptlang.org/docs/handbook/2/objects.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: optional properties, readonly, interfaces vs. intersections.
5. [TypeScript Handbook: More on Functions](https://www.typescriptlang.org/docs/handbook/2/functions.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: function type expressions, generic functions, constraints.
6. [TypeScript Handbook: Generics](https://www.typescriptlang.org/docs/handbook/2/generics.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: type parameters, generic types, constraints.
7. [TypeScript release notes](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: index of behavior changes per version. Narrowing behavior has changed across 4.x and 5.x releases; check the entry for your version.
8. [TypeScript Handbook: Type Compatibility](https://www.typescriptlang.org/docs/handbook/type-compatibility.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: structural typing.
9. [TypeScript 4.9 release notes](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-4-9.html) · Microsoft / TypeScript team · accessed 2026-10-20 · reliability: high
   - Notes: narrowing with `in` for properties not listed in the type.
